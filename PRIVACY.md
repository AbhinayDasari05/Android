# DROPGuard — User Privacy Policy & Data Consent Model

## 🛡 Data Privacy Commitments

DROPGuard is designed under strict **Privacy by Design** principles:

1. **Explicit User Consent**: Travel Mode sensor monitoring and trusted contact configuration require explicit enablement by the user.
2. **On-Demand Location Capture**: Location permissions are requested strictly for capturing last-known coordinates upon a confirmed loss event. Continuous background tracking logs are **never** recorded or shared.
3. **Local Encryption at Rest**: All emergency backup documents and credentials are encrypted on the device using AES-256-GCM. Cryptographic keys are protected by Android KeyStore.
4. **No Third-Party Analytics / Tracking**: DROPGuard contains zero third-party tracking SDKs, ad networks, or data brokers.
5. **Data Ownership & Purge Capability**: Users retain full control to delete location history, wipe Room database audit logs, or remove emergency backup files at any time via **Privacy Settings**.
